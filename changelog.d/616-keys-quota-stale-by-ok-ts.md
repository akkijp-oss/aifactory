### Fixed
- **鍵の残量が「古い」かどうかを、最後に残量を読めた時刻で判定する**。今までは「最後に観測を試みた時刻」で見ていたので、
  timer が 5 分ごとに叩き続けている限り、401 / 429 / 通信断で何時間読めなくても「鍵」画面と MCP `keys_list` は
  新鮮なふりをしていた（表示していた残量は最後に読めたときの古い値）。鍵ごとの表示もパネル全体の「古い」バッジも
  同じ基準に揃え、一度も読めていない鍵は「古い」と出す。`keys_list` と CLI `sandbox keys quota` は、試行した時刻
  （`probed` / 最終観測）と最後に読めた時刻（`ok` / `last_ok`）を並べて返す（ADR-0087）。
  「古い」バッジの案内は「timer が動いているか確かめてください」から「最後に残量を読めてから 15 分以上たっています。
  timer と鍵（認証）を確かめてください」に変えた（timer は動いていて読めていない場合を誤診していた）。
