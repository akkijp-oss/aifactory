### Added
- **赤いゲートのログが run の記録に残る**。ゲートが赤いと、その VM 内ログ（`~/gates/<名前>.log`）の抜粋（エラーらしい行 + 末尾 300 行、1 ゲート 200KB まで）を `work/gates/<名前>.log` として回収する。VM は run の終わりに初期化されるので、これまでは終わった run の「どのテストがどう落ちたか」を読む手段が無かった。コンソールの run 画面のファイル一覧と MCP の `run_show` / `read_file` からそのまま読める。実装役へ戻す依頼文にも赤いゲートの抜粋が入る（`INFO`（base でも赤・`known_red_gates`）のゲートはファイルには残るが依頼文には入れない）。行数とサイズは env `GATES_LOG_LINES` / `GATES_LOG_MAX_BYTES` で変えられる（ADR-0039）。
