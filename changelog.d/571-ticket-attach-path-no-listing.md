### Security
- **MCP の `ticket_attach(path=...)` がファイルを見つけられなかったとき、ホーム直下 / `/tmp` 直下の名前を応答に載せない**。
  「ファイルが見つかりません: <path>」だけを返します。#550 で入れた実在名の一覧は工場の成果物置き場（`read_file` が読む
  runs / tickets / logs / kit / PJ 定義 / jobs / 添付）に限ります。ホームには `routes.env.pre-deploy-20260911.patch` の
  ような退避ファイルが平置きされていて、中身が読めなくても名前だけで運用の内情（何のバックアップがいつ在るか）が
  読めるためです。`read_file` 側の一覧・上限 40 件・`.` で始まる名前の除外は変わりません。
