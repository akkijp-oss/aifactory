### Fixed
- **console: 統計の日別と期間を、run 名の日付ではなく工程の時刻で数える**。日別（`by_day`）は run ディレクトリ名の先頭 10 文字（`kb run` を起動した制御系＝UTC の日付）で切っていたため、JST の 00:00〜08:59 に始めた run が前日に載り、日付をまたいだ run も全工程が開始日に載っていた。工程の時刻を見る側の時間帯に直した日付で数えるようにし、「直近 N 日」の起点も同じ時間帯の今日から数える。画面はブラウザーの時間帯を渡し、日別の表に基準の時間帯を出す。MCP の `stats` と `/api/stats` は `tz`（`+09:00` のようなオフセットか IANA 名）を受ける。run 名の日付は変えていない。
