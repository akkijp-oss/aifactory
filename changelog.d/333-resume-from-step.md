### Added
- **止まった run を続きから回す `kb run <id> --from <step> --branch <wip>`**。人間待ちで終わった run を、新しい VM で wip ブランチの続きから、指定の工程だけやり直せる（調査と設計は走らない）。工程を省くと、記録に残った「やり直す工程」から始まる。前回の `work/plan.md` などは新しい VM に持ち込み、前回のレビュー指摘は最初の依頼文に「前回の結果（直すこと）」として入る。MCP の `ticket_run` にも `from_step` / `from_branch` が生えた（ADR-0036）
- **人間待ちで終わった run に、続きから回すコマンドを表示**。チケットのメモ・コンソールの run 画面の「結果」・`ticket_show` の実行記録に、そのまま打てる 1 行が出る
