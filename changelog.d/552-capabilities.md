### Added
- **PJ 定義に `capabilities`（この環境でできないこと）を宣言できるようにした**。`browser` / `docker` / `egress` / `gui` の 4 つで、すべて任意。書かないキーは「未宣言」として照合の対象になりません（`false`＝無いと確かめた、とは別扱い）。`project_show` から読めます（ADR-0080）。
- **票の完了条件を宣言と突き合わせて警告するようにした**。`kb new` / `intake` / `ticket_new` が本文の `## 完了条件` を走査し、この環境に無い手段を求める行を知らせます。**起票は止まりません**（rc は変わらず、警告は stderr と `ticket_new` の `warnings[]` へ）。
- **`kb capcheck [--pj P] [--all] [--json]`**。既存の票が何件警告になるかを数える読み取り専用のコマンド。DB も本文も変えません。

### Changed
- **宣言を持つ PJ の依頼文に「この環境で検証できないこと」節が入る**（全役割）。無い能力と、当たった完了条件の行が載ります。完了条件を削るためではなく、実施できないことを実施したことにしないための節です。
- **実装役の `report.md` に `## 未検証項目` が必須になった**。節が無い・空の報告は受け取らず、出力が無いのと同じ扱いで人間に戻ります（該当が無ければ「無し」と書けば通ります）。ゲートが全部緑でも、実ブラウザや docker が要る完了条件を満たした証拠にはならないためです。
- 宣言を持たないプロジェクトの挙動は変わりません（警告も出ず、依頼文の節も増えません）。
