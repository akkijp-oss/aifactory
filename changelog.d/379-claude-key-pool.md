### Added
- **Claude の鍵を制御系のプールで持ち、`take` がフラグで選ぶ**。`sandbox keys add <名前> --fable|--other` で名前とフラグ（fable に使う / fable 以外に使う）を付けた鍵を `~/.config/sandbox/keys.json`（600）に並べておくと、`take` / `reset` / `reinject` が系統ごとに、その task が前に使った鍵か、無ければフラグの合う鍵のうち最後に使ってから最も時間が経ったものを 1 本ずつ選んで VM に渡す。選んだ名前は貸出台帳に残り、同じ task の `reinject` は同じ鍵を使い続ける（使わない設定にした・消したときだけ選び直す）。候補が 1 本も無い系統は、これまでどおり PJ / 全体の env の鍵に落ちる（プールが空なら挙動は今までと同じ）。`sandbox keys list|set|rm|token` と console の「鍵」画面（近道は `g k`）、MCP の `keys_list` から見て操作でき、鍵の値は名前と末尾 4 文字より先には出ない。使わない設定にする / 消すと、その鍵を使っている貸出に `sandbox reinject` が自動で走る。run のログは `key=CLAUDE_CODE_OAUTH_TOKEN_OPUS (pool: opus-a)` になる（ADR-0043）。
