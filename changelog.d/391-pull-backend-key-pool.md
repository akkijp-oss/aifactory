### Fixed
- **pull backend（Mac / Windows / Linux）のClaudeの鍵を鍵プールから取るようにした**。これまでは制御系の設定ファイルに鍵が無いと、runnerのプロセスに残っていた古い鍵をそのままゲストへ渡していたため、鍵プールで無効化した鍵が使われ続けた。鍵はモデル系統ごとにプールから選び、工程ごとに選び直す。プールにもファイルにも鍵が無ければ、環境の鍵には落ちずに「鍵なし」でrunを一時停止する。
- **consoleとMCPが起動するジョブの鍵は `ctl.env` が正本になった**。長時間動いているMCPサーバーが起動時点の古い鍵を子プロセスへ渡し続けないよう、ジョブごとに `ctl.env` を読み直す。環境変数だけで鍵を渡していた場合は `ctl.env` に置き換える必要がある。
- **`sandbox keys list` の LAUNCHES に pull backend の起動も数えるようになった**。ゲストへ鍵の名前が渡るようになったため。
