### Added
- **鍵の残量を「鍵」画面・MCP `keys_list`・CLI `show` が同じ数字で出すことを契約テストで固定した**。同じ観測（同じ
  `keys-quota.db`）に対して 3 経路を実際に叩き、鍵ごとの残り % / 回復時刻 / 窓の始点 / いちばん逼迫している窓 /
  「古い」の判定と、パネルの最終観測・最後に読めた時刻が一致することを確かめる（要約の規則は `summarize()` の
  1 か所という ADR-0087 決定 5 の退行防止）。秘密とトークンの指紋が 3 経路のどこにも出ないことも同じテストで見る。
- **同じ名前のまま鍵を入れ替えたあとの履歴に、前の契約の観測が 1 点も残らないことを確認テストにした**。残量グラフが
  別の契約の点と線でつながらないのは、入れ替えを見つけた周が観測を打つ前にその鍵の履歴を捨てているからで
  （ADR-0090 決定 1）、表示側は世代を見分けなくてよい。その前提を表示に渡る形（`/api/keys/history` と
  `history_view`）の側から固定した。入れ替えていない鍵の履歴は巻き添えにしない。表示・判定の変更は無い。
