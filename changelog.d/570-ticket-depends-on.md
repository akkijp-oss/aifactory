### Added
- **チケットに先行条件（`depends_on`）を書けるようになり、管理役（PM）が未完了の先行票を持つ票を次に選ばなくなった**。`kb new --depends 534,535` / `kb set 538 --depends 534,535,536,537`（`''` で消す）、`intake --depends`、MCP / HTTP の `ticket_new` / `ticket_action(set)` の `depends_on` から書ける。値は票番号のカンマ区切りで、`kb show` / `ticket_show` / `ticket_list` から読め、変更は `kb history` に残る。**書くのは人だけで、本文の自由文から依存を推測しない**（誤検知と取りこぼしの両方が出るため）。`GET /api/pm` は先行票がまだ終わっていない票を飛ばして次の todo を選び、候補が全部そうなら `next.reason` と判断ログの `reason_code` に新しい語 `blocked_by_dependency` を返す——「回すチケットが無い」（`no_todo`）とも「板を読めていない」（`board_unreadable`）とも別の値で、飛ばした票と未完了の先行票は `facts.skipped_by_dependency` に残る。`depends_on` を書いていない票の挙動は変わらない（列が無い頃の `kanban.db` には `kb` が起動時に足す）。背景: 提案モードの PM の第 1 号が、本文で「先行票の着地後に起動する」と定めて止めてあった #538 を「今すぐ起動せよ」と言った（ADR-0077）
