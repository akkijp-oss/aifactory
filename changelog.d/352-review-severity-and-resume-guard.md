### Added
- **レビューの軽微な指摘は もう 1 周だけ実装に戻る**。reviewer が `review.md` の FAIL に `severity: minor` と書いたときに限り、
  戻せる回数（`max_loops`）の上限を **1 回だけ** 超えて implement に戻す（1 遷移につき 1 回きり）。`severity: major` と無指定は
  従来どおり人間へ。1 行目の `# レビュー: PASS|FAIL` の契約は変えていない（ADR-0053）。

### Fixed
- **再開時に前回のレビューを渡すのは FAIL だったときだけ**。review が PASS したあとの工程（`sync` の衝突や `pr`）で止まった run を
  `kb run <id> --from` でやり直すと、前回の**合格した** `review.md` が「レビュー指摘（直すこと）」として実装役の依頼文に入っていた。
  1 行目が FAIL のときだけ渡し、それ以外は止まった理由 1 行を添える。
- **同じチケットの二重再開を断る**。`kb run <id> --from` は、台帳が実行中でその run もまだ終わっていないときは rc≠0 で拒否する
  （wip ブランチが後勝ちで上書きされるため）。承知の上なら `--force`。
