### Added
- **console: 工程詳細からその工程の yml ブロックを直せるようにした**。`timeout_min` / 分岐 / 読み書きするファイル / `brief` など、これまでモデル以外は制御系に入って手で直すしかなかった項目を、画面から変えられる。出るのも書けるのも **その工程のブロック（`- id: <工程>` から次の工程の直前まで）だけ**で、ファイル全体は出ないし書けない。モデルの欄とは画面の中で双方向に同期する。工程の `id` と担い手の種類（`role` / `code`）は変えられない。保存の流れは今までと同じで（下見 → 確認 → `base_sha256` → `.bak-<時刻>` → `logs/config-changes.jsonl`）、読めない書き方のときは 1 バイトも書かずに理由を出し、入力は消さない。書かれるのは当該ブロックだけで、ほかの工程・ファイル先頭のコメント・並び・引用は 1 文字も変わらない（ADR-0073）
