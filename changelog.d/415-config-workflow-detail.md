### Added
- **設定画面から workflow の工程を読めるようにした**。workflow の名前と工程が本物のリンクになり、
  一覧 → workflow 詳細 → 工程詳細 を Tab と Enter だけで往復できます。工程詳細では担い手（役割か機械）・
  この workflow での指示・読むファイルと書くファイル・時間の上限（定義に無ければ既定と添える）・
  うまくいったとき / いかなかったときの行き先（戻す回数と、超えたときの行き先）・実効モデルが読めます。

### Changed
- **設定画面の「流れ」を、成功の道と「うまくいかなかったときだけ回る工程」に分けた**。`feature` の `resolve` は
  `sync` が失敗したときだけ回る工程ですが、定義の順に並べていたので `sync → resolve → pr` と常に回るように読めていました。
- **実効モデルを工程ごとに解いて出すようにした**。クラス（役割の既定か、その工程の `model_class` か）→ 経路
  （`MODEL_<クラス>`）→ モデル名、の順に出します。code の工程は「機械が実行します。モデルは使いません。」と出し、
  モデル名は出しません。実行時に `CLAUDE_MODEL` で上書きされることがあり、その値は設定からは分からないので、
  実際に使ったモデルは統計画面へ案内します。
- 定義が読めない workflow や、schema に無いキー・enum 外の役割も隠さず「読めない項目」として並べます。
