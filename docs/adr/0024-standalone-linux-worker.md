# ADR 0024: Proxmoxに依存しない単体Linuxワーカー

- 状態: Accepted
- 日付: 2026-09-07

## 決定

専用Linuxインスタンスへ直接導入する `linux-pull` backendを追加する。ハイパーバイザーのAPI・VM名・clone/snapshotは使わない。既存のHTTPS pullキュー、操作ジャーナル、排他的lease、成果物回収を共有する。

rootのサービスはワーカーの接続トークンとジャーナルを管理する。実際のコマンドは専用の一般ユーザーでsystemdの一時サービスとして実行し、cgroupごと終了を確認する。インストールされたワーカーサービスと操作サービスをBindsToで結び、ワーカーの異常停止でも操作サービスを停止する。状態が確定しなければ予約を保持し、入力を自動再実行しない。

computer-useはX11用の一般ユーザーのデスクトップエージェントを使う。既存の専用X11セッション、またはXvfb/Openboxによるヘッドレス環境を選択する。ループバックだけで待ち受け、専用トークンで認証する。WaylandをX11と同等には扱わず、未対応として拒否する。

## 制約

リセット範囲は作業フォルダーだけ。デスクトップ・アプリ・ユーザー設定は残る。Linuxインスタンス自体を実行境界にし、個人のホームや管理権限をタスクへ与えない。ネットワークは導入先のファイアウォールで制限する。GUIや外部のサービスを介して起動された処理まで、コマンドのcgroupで停止できると保証しない。
