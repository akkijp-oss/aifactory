# ADR 0089: console の左ナビは「頻度」ではなく「何をする画面か」で 3 群に分ける。見出しはリンクにせず、選択は色と `aria-current` の両方で示す

- 状態: Accepted
- 日付: 2026-09-16
- 関連: ADR-0019（コンソール UX。「頻度で配置する」のナビ順を本 ADR が置き換える）、
  ADR-0080（実行環境の能力の宣言と警告）、#586（「AI Factory Manager」は英字のまま）、#588（`n-pm` の札は置かない）

## 状況

ADR-0019 は「**頻度で配置する**」を決め、左ナビを頻度順（ボード / AI Factory Manager / 起票 / 実行記録 /
ジョブ / sandbox / 統計 / 鍵 / ログ / 設定）の 1 列にした。当時は 7 項目だった。

その後に AI Factory Manager・統計・鍵が足されて **10 項目**になり、次の 2 つが起きている。

- **群が見えない**。日常のチケット操作（ボード・起票）と、実行の監視（実行記録・ジョブ・ログ）と、
  たまにしか触らない管理（sandbox・鍵・設定）が同じ見た目で 1 列に並ぶ。
- **順が意味を伝えない**。ボードと起票の間に AI Factory Manager が入り、ログは実行記録・ジョブから離れている。
  「頻度順」は作った人の見立てであって利用の実測ではなく、項目が増えるたびに挿し込む位置の根拠が弱くなる。

「頻度順」という語は実装とドキュメントの 5 か所（`index.html` の先頭コメント、`console/UX.md`、
`console/README.md`、ja / en のガイド）に同じ 10 語の列挙つきで書かれていて、並べ替えるたびに全部が古びる。

## 決定

1. **並びの根拠を「頻度」から「何をする画面か」に変える。** 10 項目を次の 3 群・この順で常時表示する。

   | 群 | 項目（上から） |
   | --- | --- |
   | チケット | ボード、起票 |
   | 実行・監視 | AI Factory Manager、実行記録、ジョブ、ログ、統計 |
   | 管理 | sandbox、鍵、設定 |

   ボードは先頭に残し、起票を隣に置く。AI Factory Manager は実行を見る群の先頭。
   実行記録とジョブは役割が違うので統合しない。

2. **群の見出しはリンクにしない**（`<a>` にせず、`data-nav` / `href` を持たせない）。
   押せそうに見えるのに何も起きない要素を作らないため。見出しは `role="group"` の
   `aria-labelledby` から参照させ、支援技術にも群として読ませる。

3. **見出しの文言は `strings.js` の `T.nav.group.*` に置く**（HTML に日本語を直書きしない）。
   画面に出る日本語は 1 か所に集めるという ADR-0019 の約束をそのまま適用する。

4. **DOM 順を正本にする。** 視覚順だけを変える CSS（`order`）は使わない。DOM 順がそのまま
   表示順・読み上げ順・Tab 順になる（`console/UX.md`「読む順の約束」）。

5. **選択中の項目は背景色と `aria-current="page"` の両方で示す。** 付け外しは `route()` の 1 か所で行い、
   HTML には直書きしない。詳細画面で親を選ぶ既存の対応（`#/ticket*`→ボード、`#/run/*`→実行記録、
   `#/job/*`→ジョブ）はそのまま流用する。

6. **識別子と近道の対応は変えない。** `href` / `data-nav` / 件数札（`n-board` / `n-runs` / `n-jobs` /
   `n-sandbox` の 4 つ。`n-pm` は置かない＝#588）、件数の対象範囲（全 PJ）と更新間隔、
   `g` + 頭文字の割り当て、ナビの幅 196px、表示名「AI Factory Manager」（#586）は据え置く。
   `KEYS` の**並び**だけをナビと同じ順にする（`?` の一覧が画面と同じ順に出る。行き先の対応は不変）。

## 理由

- **3 群は利用の実測ではなく画面の役割からの分類**である。頻度は測っていないので、測っていない根拠より
  「何をする画面か」という読めば分かる根拠を採る。項目が増えたときの置き場も群で決まる。
- **折りたたみやサブメニューは導入しない。** 10 項目は全部見えたままにできる。折りたためば
  「今どこにいるか」を見るのに 1 手増え、閉じた群の中の項目は探せなくなる。
- **`aria-current` は色の代わりではなく追加**である。既存の選択背景は残す。色だけが手掛かりだと
  読み上げと高コントラスト表示で選択が消える。値は WAI-ARIA の慣例どおり `"page"` を使う。
- **`n-pm` を復活させない。** 札を置いて誰も書かなければ「常に 0 件」と見分けが付かない（#588）。

## 結果

- ADR-0019 の「頻度で配置する」のうち**ナビの順だけ**が置き換わる。摩擦の段階・文言の集約・
  `g` + 頭文字の近道という他の決定は有効なまま。ADR-0019 の本文は書き換えない（この ADR が上書きする）。
- 「頻度順」と書いた 5 か所（`console/static/index.html` の先頭コメント、`console/UX.md`、
  `console/README.md`、ja / en のガイド）を 3 群の記述に揃える。`console/README.md` と
  `docs/ledger.md` の履歴行は当時の記録なので残す。
- 群と順序、見出しが非リンクであること、識別子 10 個が増減しないこと、`aria-current` の付け外しは
  `console/tests/test_console.py::test_rail_is_three_groups_in_ticket_order` が固定する。
  順を変えるとこのテストが落ちるので、次に並べ替える人は本 ADR に戻ってくる。
- **見た目の確認はこの ADR の範囲外**。実装環境は `browser` / `gui` を持たない宣言（ADR-0080）なので、
  解像度ごとの描画・Tab / Enter の目視は着地後に画面のある環境で行う。崩れていれば追い票で直す。
