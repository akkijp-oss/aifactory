# ADR 0023: 専用VMのcomputer-useをpullワーカーに追加する

- 状態: Accepted
- 日付: 2026-09-07

## 背景

CLIでのチケット実行に加え、Mac・WindowsのGUIを確認する必要がある。WindowsサービスのSession 0はログインユーザーの画面とは別であり、Macでは画面収録とアクセシビリティの許可が必要。

## 決定

既存のpullキューと排他的leaseを使い、専用ゲスト内に限定した画面操作を提供する。外部向けの新しいGUIネットワークサービスは設けない。

共通Goクライアントは、限定したJSON操作とstdio MCPを公開する。MacはSwiftのネイティブヘルパーを起動し、Windowsはログインユーザーの常駐タスクへループバック経由で接続する。Windows用の専用トークンをワーカー接続トークンから分離し、プロキシとリダイレクトを無効にする。

`computer_use` を明示したプロジェクトのエージェントにだけMCP設定を渡す。制御系からの直接操作には独立した予約セッションを作り、他のチケットへ割り込まない。操作の完了が不明な場合は入力を自動再実行しない。

画像は最大幅1024ピクセルのPNGとし、クリック座標を実画面へ変換する。workflowは最新の画像を成果物として通常のハッシュ検証と回収に含める。直接セッションは制御系に画像と操作履歴を保存する。

## 結果と制限

Macは許可を保存した基準VMからcloneし、返却時にゲストを削除する。Windowsは作業フォルダーだけを初期化するため、画面やアプリの状態が残る。画面操作がOS全体の初期化を保証するわけではない。ロック画面、保護されたUAC画面、動画・音声・ドラッグは対応範囲外。

セットアップと運用は[computer-use](../computer-use.md)を参照。

Macの長文入力では合成キーイベントの連続送信で文字欠落を観測したため、クリップボードへUnicode文字列を書き、CMD+Vで貼り付ける。改行やサロゲートペアを分割しない。ゲストのクリップボードは置き換わる。
