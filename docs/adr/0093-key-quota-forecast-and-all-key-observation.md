# ADR-0093: 利用枠の統合グラフと全鍵の観測

## 状況

ADR-0087 の表示は枠別のバーと切替式の履歴に分かれ、回復まで残量が持つか判断しにくい。無効な鍵と Fable 非割当の鍵は観測されないため、配車設定を変える前に残量を確認できない。

## 決定

- 配車の有効・用途フラグは観測対象の判定に使わない。auto / full は毎回全鍵に Fable で問い合わせる。共通枠が返らなければ安いモデルでも問い合わせる。明示的な cheap は残す。旧 full interval 設定は廃止する。
- Fable の取得失敗を共通枠とは別に保存・表示する。既存 DB には列を追加するだけとする。キー削除・差し替え中の応答を捨てる契約とプローブの排他を維持する。有効フラグの変更では応答を捨てない。
- 鍵を選び、5h / 7d / 7d_oi を一つの時間軸で見る。既定は過去 7 日・未来 7 日。実測は実線、予測は破線。実測のない区間や異なる reset の観測を結ばない。合成した window_start は実測に含めない。
- 予測は最新の実測の時点で、窓の開始からの平均消費率を計算する。ページ更新によって消費率を変えない。残量 0% と回復 100% の時刻を正確な頂点とする。次回以降は一定間隔の回復と同じ消費率を仮定する。
- 15 分を超えて古い観測、回復時刻不明・経過済み、開始から窓長の 5% 未満の場合は予測を出さず理由を表示する。窓ごとの履歴を使うので共通枠の取得が Fable の鮮度を更新することはない。

## 理由

観測のコスト削減より全枠の鮮度と判断しやすさを優先する。設定と観測を分離し、取得不可を残量ゼロや横ばいの予測と取り違えない。

## 結果

従来より問い合わせが増える。観測リクエストも少量の利用枠を消費する。予測は保証ではなく、将来の利用と実際の回復時刻によって変わる。過去に取得していない履歴は復元しない。

## 状態

採用。ADR-0087 の観測対象・周期・表示と、ADR-0090 の観測中に無効化された鍵の扱いを更新する。
